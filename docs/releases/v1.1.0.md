# v1.1.0

This release expands the bilingual portfolio with hiring information, engineering notes, project evidence, and improved contact options.

- Add a hiring overview covering role fit, strengths, and collaboration.
- Add two engineering notes in English and Spanish on failure controls and consistent experiment assignment.
- Add a guided API Gateway walkthrough with authentication, timeout, and circuit-breaker scenarios, published configuration, and pinned source/test links.
- Include an attributed experimentation dashboard screenshot.
- Redesign the inquiry form with a responsive split-card layout, reusable fields, localized prompts, and theme-aware styling.
- Add copy-email feedback and optional Netlify Forms inquiries with localized confirmation pages.
- Add optional Plausible engagement measurement with bounded event metadata and browser privacy preferences.
- Apply Astro view transitions to every page, with reduced-motion support.
- Add GitHub Actions validation and desktop/mobile browser checks.
- Configure Netlify deployment and the `derian-cordoba.me` production domain.

Contact form delivery requires Netlify Forms detection and notification settings. External analytics remains disabled until a Plausible script URL is configured. See [deployment setup](../deployment.md).
